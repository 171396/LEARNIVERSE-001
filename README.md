# Learniverse

A platform where entrepreneurs and startup builders across Africa share ideas,
get feedback, and find the people they need to build them.

## v1 scope
- Sign up / log in
- Post an idea (title, description, "looking for")
- Browse the ideas feed
- Idea page with threaded discussion

## Not in v1
Profiles, learning resources, moderation tools, real-time features

## Stack
React + Vite, Supabase (Postgres + auth), Vercel
